Template Missing

Email template not found

The requested email template could not be located. This usually means the template name is incorrect, the file has not been created yet, or it was moved from its expected location.

Review the template identifier being requested by the application and confirm that a matching file exists in the configured email templates directory.

What to check

Verify the template filename, confirm the path is correct, and make sure the deployment includes the latest email view assets.
